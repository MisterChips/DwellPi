Raspberry Pi based central heating/boiler controller. Python based.

Hardware: Thermostat (to be placed in usual central heating thermostat position) consisting of: RaspPi with attached, via GPIO, digital DALLAS DS18B20 temperature sensor, and serial RF module. 16x4 LCD display, 5 button menu UI, Web UI.

RF Relay switching unit (placed near boiler (but not too near!!! EMP risk)): Mains powered, RF/DualRelay unit. Used to control 2 circuits for Central Heating and Hot Water separately.
